# 台股盤中多空助手規則（偏做多）

本文件為 Cursor 雲端助手實際使用的規則彙整，方便本地搭配 FinMind 行情與康和 API 庫存使用。

## 1. 運作時段

- 交易日：週一至週五
- 時區：Asia/Taipei
- 盤中刷新：09:00–13:30，建議每 5 分鐘一次
- ≥13:30 或非交易日：改出收盤總結，改訂次一平日約 09:00 開盤報告

## 2. 資料來源

### 行情（必要）

- `FINMIND_TOKEN` + FinMind `DataLoader`
- `taiwan_stock_tick_snapshot`
  - 大盤：`001`
  - 櫃買：`101`
  - 股票池與自選
- `taiwan_futures_snapshot(futures_id="TXF")`
  - 取**當日** `total_volume` 最大的合約（避免隔夜舊月）
- 欄位：
  - 漲跌用 `change_price`（不是 `change`）
  - `volume_ratio` 常為 `0.xx` 比值 → ×100 成「約昨天全天的 xx%」
  - `total_amount ÷ 1e8` = 億
- 過濾非當日 `date` 的快照（防隔夜殘值）
- 不使用：every5seconds_index／當日 tick／kbar／當日 TAIEX daily（除非另算均額）

### 庫存（本地康和，選用）

- 雲端環境**無法**直接連康和 API（需 Windows、.NET、帳號申請開通）
- 本地可：
  1. 康和官方 API／conrich 查庫存後寫入 `positions.json`
  2. 或手動貼庫存給助手
- 介面約定見 `twse_bias/brokers/concord_stub.py` 與 `positions.example.json`

## 4. 量能時段門檻（綠／黃／白）

單位：`volume_ratio × 100`（約昨天全天成交量％）

| 時段 | 綠 | 黃 | 白 |
|------|----|----|----|
| 09:00–10:00 | 50 | 35 | 25 |
| 10:00–11:00 | 70 | 55 | 40 |
| 11:00–12:00 | 90 | 75 | 55 |
| 12:00–13:30 | 105 | 90 | 70 |

計分：≥綠 +2；≥黃 +1；＜白 −1；白～黃之間 0

## 5. 大盤評分與燈號

分數加總：

1. 現價 vs 開盤：上 +2／下 −2
2. `change_rate`：≥1% +2；≥0.3% +1；≤−1% −2；≤−0.3% −1
3. 量能：依上表
4. 櫃買現價 vs 開盤：上 +1／下 −1
5. 期現差（期貨收盤 − 現貨）：＞50 +1；＜−50 −1

燈號：

- ≥4 綠燈
- ≥2 黃燈
- ≥0 白燈
- ＜0 紅燈

## 6. 價位門檻（以當日 開／高）

設 `R = 高 − 開`：

- 做多線 = 高 − 0.25×R
- 保守線 = 高 − 0.382×R
- 減碼線 = 高 − 0.50×R
- 開盤防守 = 開盤價

## 7. 倉位檔位（必出）

依大盤現價相對門檻（並參考燈號／量能）：

| 條件 | 本輪倉位檔位 | 空手 | 已持股 |
|------|--------------|------|--------|
| ≥做多線 且 綠燈 且 量能≥黃 | **積極加倉** | 可開／加到偏滿（強勢回測開盤或站穩做多線） | 加倉強勢股 |
| 做多～保守之間 | **偏多持有** | 可小開，不追高 | 抱住，小加即可 |
| 保守～減碼之間 | **保守觀望** | 慎開／少開 | 不加倉 |
| ＜減碼線 但仍＞開盤 | **減碼** | 暫不開 | 降到半倉或更低 |
| ＜開盤 或 紅燈 | **清倉防守** | 空手 | 大幅減／清 |

個股層：

- 跌破開盤：不開、不買；有倉則優先減
- 平開／站開且夠強：可開或續抱
- 漲多近高：不追；已有倉可先減獲利

## 8. 可做多標的篩選

綠／黃燈：

- 條件：站上開盤 + 漲幅夠（建議 ≥0.3%）+ 強度分
- 強度粗分：站開 +2／破開 −2；漲幅 ≥2% +3、≥1% +2、≥0.5% +1、＜0 −1；量比 ≥150% +2、≥100% +1
- 輸出最多 6 檔，按強度再按漲幅排序
- 格式：`名稱(代碼)｜族群｜價（漲跌／%）｜量比昨｜強度`

白／紅燈：改列「相對強勢（僅供優先順序參考）」，勿空白。

## 9. 輸出格式（純文字繁中）

禁止：貼圖、matplotlib、HTML、sparkline／ASCII 走勢欄。

固定區塊：

1. `時間｜燈號｜判定（分數）`
2. 大盤／成交金額／量能白話／此時間門檻／櫃買／期貨+期現差／價位門檻  
   （各佔一行，行間空一行）
3. **【倉位建議】**  
   - 本輪倉位檔位：…  
   - 積極加倉／可開倉：…  
   - 保守持有／觀望：…  
   - 減碼／停損：…  
   （若有 `positions.json`，改寫成「對你現有部位」的加減碼）
4. 建議一句 + 依據（各佔一行並空一行）
5. 【可做多標的】或【相對強勢】；【觀察股】  
   （編號一檔一行，檔間空行）

結尾：僅分析建議，不構成投資建議。

## 10. 歷史檔

- 路徑建議：`/tmp/twse_intraday_hist.json`（雲端）或本地 `data/intraday_hist.json`
- 跨日重置 `date` 與 `points`

## 11. 本地快速指令

```bash
export FINMIND_TOKEN=你的token
pip install -r requirements.txt
python -m twse_bias.cli report
```

有康和庫存時，先寫入 `data/positions.json`（格式見 example），再：

```bash
python -m twse_bias.cli report --positions data/positions.json
```
